# Project Guide

This is a standard Vite + React project (Quran Companion AI) using TanStack Start & React Router.

## Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Configure environment variables in `.env`:
   ```env
   GEMINI_API_KEY="your_gemini_api_key"
   ```

3. Start dev server:
   ```bash
   npm run dev
   ```
